# AudioVisualStudio

Projeto acadêmico com frontend em React e backend em Java com Spring Boot.

## Estrutura

- `frontend/`: código-fonte do frontend, configurações e dependências declaradas.
- `backend/`: código-fonte do backend Java, arquivos Maven e recursos.
- `audiovisual_studio.sql`: script SQL do banco de dados.

As dependências instaladas (`node_modules`) e arquivos gerados pelo build não são incluídos no repositório.
